# 当前实现状态

当前版本为可运行的开发版本。此文只说明模块能力与验证边界，实验原始材料、项目记录、临时部署配置和本机路径不随源码发布。

## 已实现

| 模块 | 当前能力 |
| --- | --- |
| 工作台 | 空白项目启动、上传设计文档、选择已登记仓库、四阶段结果、详情、暂停与继续、预算设置、历史分析、报告导出 |
| 文档处理 | Docling 解析 Word、PPT、带文字 PDF；原件摘要与原始内容定位；按需读取而非默认固定分片 |
| 标准库 | PCI DSS v4.0.1 离线结构化导入、原文保留、固定版本入库、FTS 检索、全文读取与需求匹配 |
| 安全需求 | 设计事实与显式/推导需求、验收条件、技术相关性与正式适用性分离、条件性标准需求、自动需求复核 |
| 威胁建模 | Mantis 原生代码分析、架构与威胁模型，tree-sitter 导航与只读源码快照 |
| 实现检查 | 每项需求对应独立任务，每条验收条件恰好提交一次；原文、标准关联、检查状态与代码位置持久化 |
| Findings | 原生规划、研究、去重、静态复核、质疑、攻击链、评级、反思与报告；已排除候选单独保留 |
| 模型调用 | 独立 DeepSeek 网关、受限端点、原子预算、累计用量、瞬态故障重试与等待恢复、持久化会话 |
| 结果提交 | 保存原始模型输出、具体工具 Schema、任务归属和来源验证、原子提交；不补造分析结果 |
| 数据库 | SQLite WAL/FTS5，版本迁移前备份、结构化标准版本、任务、读取记录、模型返回与产物 |
| 语言 | 默认英文，中文设置直接作用于技能和 Prompt；运行语言固定，已有结果不二次翻译 |
| 部署 | 两个容器、前端同源提供、源码/标准/模型只读挂载、分析服务内部网络、网关独立持有密钥 |

模型输出校验失败不会转换成成功状态。搜索命中或历史会话读取不代替当次实际读取；实现判断必须引用已读取源码。固定任务关联由程序提供，分析字段保持原始返回。对应关系完整不等于结论准确。

## 验证情况

自动回归覆盖任务与数据库提交、语言策略、预算及恢复、源码引用、严格工具协议、原生 Mantis 阶段和静态权限边界。前端通过 TypeScript 与生产构建。容器已在 Linux ARM64 上构建和启动，其他架构尚未验收。

真实模型接口、工具往返和四阶段链路已完成运行与持久化核对。首次完整实验通过开发调试及续跑完成，尚未证明完全无人干预的稳定性。Findings 未做人工有效性验证，历史文档需求语义验收曾出现遗漏与适用性误判；不能将流程完成表述为语义质量通过。

## 尚未完成或未验收

- 完整无人干预运行的稳定性及所有契约异常的自动恢复。
- 需求准确性、遗漏率、标准匹配和 Findings 精确率/召回率的标注数据集验收。
- 扫描页 OCR、复杂图像与图形语义覆盖，以及旧 Office 转换的完整交付。
- 跨运行需求谱系、增量失效复用和更大项目的成本/覆盖验收。
- 操作系统级域名出口限制、所有 CPU 架构及干净环境离线交付验收。

## 产品边界

系统完全静态分析，不构建或运行目标程序，不做动态复现、沙箱验证或自动补丁。静态支持不代表部署状态已确认；外部控制与正式合规范围未知时分别保留未知或外部材料需求。PCI DSS 候选检索不证明全标准覆盖，也不提供合规认证。

发布源码包含最小自动测试夹具，不包含演示项目、实际输入源码、设计材料、标准全文、模型权重、API 密钥、运行数据库或实验报告。部署时需自行提供这些资源。
