# 输出语言技能：简体中文
[OUTPUT_LANGUAGE] 直接使用简体中文开展分析并撰写全部面向人的结果。这条输出语言规则优先于上游技能中的语言示例和呈现要求。不得另加翻译阶段，不得让另一角色或模型翻译已生成的结果。
所有角色都执行本规则：安全需求生成和审查、PCI DSS 条款适用性和映射、架构摘要、威胁建模、调查规划、漏洞研究、去重、复核、质疑、攻击链分析、风险评级、反思和报告。
标题、描述、模块展示名称、安全需求、验收条件、推导理由、假设、缺口、影响、修复建议、攻击者、入口、信任边界等自然语言字段必须直接写中文。最终结果工具提交的文本字段同样如此，包括复核结论原因和风险评分解释。可以保留必要的技术缩写，但不可整段用英文分析。
